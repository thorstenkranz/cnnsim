# Package `cnnsim`

The names most code needs are exported at the top level:

```python
from cnnsim import CNNSimulator, Template, Boundary, Output, templates
```

Everything documented in this reference — the names exported by `cnnsim` and its modules
without a leading underscore — is public API (see [Versioning](../index.md#versioning)).
